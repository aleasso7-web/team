# 🏰 La Grande Avventura di Ale

Un gioco di avventura **testuale** (si gioca scrivendo comandi!)
scritto in **Python super semplificato**, pensato per imparare divertendosi.

## 🎮 Come si gioca

1. **Installa Python 3** sul tuo computer: https://www.python.org/downloads/
2. **Scarica i file**: clicca il pulsante verde *Code* → *Download ZIP* → estrai
3. Apri il terminale nella cartella del progetto
4. Scrivi:
   - **Windows**: `python gioco/main.py`
   - **Mac / Linux**: `python3 gioco/main.py`
5. Usa i comandi: `aiuto`, `guarda`, `vai foresta`, `prendi mela`, `inventario`, `esci`

> 💡 **Niente Python?** Puoi giocare anche dal browser con **GitHub Codespaces**:
> clicca *Code* → *Codespaces* → *Create codespace* → nel terminale scrivi `python3 gioco/main.py`

## 📏 Il nostro stile "super semplice"

- Solo comandi base di Python: `print`, `input`, `if`, `while`, liste, dizionari, funzioni semplici
- **Niente classi, niente librerie complicate**
- Tutti i nomi e i commenti in **italiano**
- Ogni pezzo di codice spiegato passo passo, dentro il codice stesso
